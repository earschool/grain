# Change 007: Comparison View

**Status:** Draft stub
**Priority:** P2
**Phase:** 2/3

## What

Upload same song twice (before/after practice) and overlay pitch tracks to compare improvement.

## Why

Practice tracking is a compelling use case — showing pitch improvement visually and objectively is a strong retention driver.

## Scope

- Select two existing analyses of the same song
- Overlay pitch tracks (two colors, same timeline)
- Membership-gated

## Open Questions

- How does user indicate two analyses are "the same song"? (manual tag, or duration similarity?)
- Overlay: side-by-side or direct overlay?
- Compare other panels (dynamics, vibrato) or pitch only?

## Acceptance Criteria (stub)

- [ ] Two analyses selectable for comparison
- [ ] Pitch tracks overlaid on same canvas in two colors
- [ ] Membership-gated
